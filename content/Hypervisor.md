A hypervisor is a software that enables multiple virtual machines (VMs)—each with its own operating system (OS)—to run on one physical server. 

### Etymology

The term hypervisor is a variant of supervisor, a traditional term for the kernel of an operating system: the hypervisor is the supervisor of the supervisors, with hyper used as a stronger variant of super.

### History

* The concept of virtualization began with IBM's System/360 in the 1960s, where the CP-40 and CP-67 systems allowed multiple virtual machines to run on a single physical mainframe.
* Introduced in 1972, IBM VM/370 was one of the first widely used systems to implement virtualization, allowing different operating systems to run concurrently on IBM mainframes.
* In 1999, VMware introduced its first product, VMware Workstation, which allowed multiple OSes to run on x86 hardware. This marked a significant turning point for virtualization.
* Launched in 2003, Xen Project became an open-source hypervisor that popularized virtualization in Linux environments.
